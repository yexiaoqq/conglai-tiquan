## 2. 构建链路（八步，build_ui.sh）

1. 编译 stub（androidx / material 的最小替身）
2. 编译 MainActivity.java
3. d8 → dex
4. baksmali：把原 APK 的 classes.dex 反汇编
5. 把新 MainActivity 的 smali 注入回反汇编结果
6. 注入新资源（res/**）
7. apktool b 重新打包
8. zipalign.py 对齐 → apksigner 签名
产出：conglai-md3-ui-signed.apk

关键策略：本工程不是从零编译整个 App，而是「反汇编原 APK → 只替换 MainActivity + 资源 → 重打包签名」。所以：
- 改 UI/逻辑 → 只需重编 MainActivity.java。
- 改资源 → 只需替换 res/**。
- 不要试图编译 ExploitRunner/BootReceiver 的逻辑，它们是桩。
